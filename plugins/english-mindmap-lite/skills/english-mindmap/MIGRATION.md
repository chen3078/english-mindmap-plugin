# English-mindmap-2026.10.27 · 三类图片精简迁移包

版本：2026.10.27.1。基于原完整版2026.10.26.3独立派生，原包与原安装不变。

## 安装与调用

将整个 `english-mindmap` 文件夹复制到目标应用实际使用的 skills 目录，保留所有子目录与字体许可证。与原来的 `xhs-english-mindmap-series` 使用不同名称，可以并存。让应用重新发现技能，确认读取本目录和本版 release.json。

调用示例：

> 使用 $english-mindmap，主题：牛奶，系列：食物篇。只制作思维导图完整版、思维导图练习版和中英双语问答图片。

问答图片按真实内容分页，三类内容不代表只出三张图。默认不生成逐题视频配图、独立英文稿、社交文案或其他学习成品。

## 环境与自检

需要Python 3.10+、Pillow，以及能够接收实际参考图的图像生成工具。图片服务账号与额度不包含在包中。

在本技能目录执行：

```text
python -m pip install -r requirements.txt
python -X utf8 scripts/verify_bundle.py
python -X utf8 scripts/test_regressions.py
```

本版保留16张与三类图片有关的认可参考、所有相关画风、内容规划、问答分页、四项双语文字、连线实际像素与整齐检查。两张视频专用参考及视频/英文稿/文案生成入口已移除。

## 生产与交付边界

内容、分支与问题仍由内部 manifest.json 统一管理；分支与问题可以一对多。每张图片都要对照真实参考、核对文字和图片含义。保留已确认内容及用户指定的视觉审核步骤，不要重复索取已有确认。

内部工作目录保存生产证据、提示记录、底稿、连线计划与验收图库；正式给学习者的主题图片包只包含3类成品PNG。先运行默认 `check_release.py`，再用 `package_images.py` 打包，具体命令见 SKILL.md。

## 验证范围

本次验证范围是精简后的依赖、三个图片类型的发布与打包行为、保留的连线/问答/证据拒绝规则、包完整性及同机新目录解压运行。回归测试使用合成数据与明确标记的模拟记录，只验证程序行为，不代表真实图片美学通过。未新增主题生图，尚未验证另一使用者账号的端到端生成结果；实际新主题仍须逐图检查。
