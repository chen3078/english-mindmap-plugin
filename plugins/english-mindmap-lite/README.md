# 英语口语思维导图·三类图片版

选一个主题，制作**完整版思维导图、无字练习版、中英双语问答图片**。三类不等于三张，问答按完整内容分页。适合英语初学者自练、亲子看图问答与教学素材制作。

这是独立插件 `english-mindmap-lite` v1.0.0，内置用户指定的 **English-mindmap-2026.10.27 / skill 2026.10.27.1**，与原完整版 `english-mindmap` 并存。原画风、内容规划、参考职责、连线像素与逐页检查要求保留。

**从这里开始：[中文迁移与使用教程](INSTALL.zh-CN.md)。** 不需要原聊天记录或作者电脑上的文件。

## 在线安装

```text
codex plugin marketplace add chen3078/english-mindmap-plugin
codex plugin add english-mindmap-lite@english-mindmap
```

已添加过该来源时，先执行 `codex plugin marketplace upgrade english-mindmap`。安装后重启应用并新建聊天，选择“英语口语思维导图·三类图片版”，运行首次使用引导。插件依赖宿主提供真实生图、参考图输入和本地Python能力，安装成功不等于账号具备生图权限。

## 开始生成

> 使用三类图片版的 $english-mindmap，主题：面包，食物篇，面向成人英语初学者。先给出完整中英双语问答供我确认，再制作完整版导图、无字练习图和全部双语问答图片。

内容确认后回复：

> 内容确认，请继续生成全部图片，按本插件的样张、连线和逐图验收标准检查，最后交付纯图片压缩包。

输出为3:4、1086×1448 PNG；练习版不含文字、数字、署名及空编号圈。完整版和双语页保留小号署名“新陈代谢（英语版）”。本版不制作视频素材、独立英文问答稿、社交文案或额外学习成品。
