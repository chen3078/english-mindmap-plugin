# 三类图片版｜交付与验收记录

项目：`english-mindmap-lite` v1.0.0；日期：2026-10-27。

## 交付目标与依据

让没有原聊天背景的接收者，通过GitHub或完整插件ZIP，在具备本地执行与真实图片生成能力的Codex环境中，继续制作新主题的三类图片。用户指定源文件为 `English-mindmap-2026.10.27.zip`，要求原版条件与质量不变，仅减少学习成品种类；用户明确选择“另建精简版插件，与原完整版并存”。

本次交付继续生产能力，已有的警察主题是本机实际生成案例。原完整版插件 `english-mindmap` v1.0.0及其skill 2026.10.26.3不被精简版替换。

## 固定项、变化项与参考职责

- 固定：3:4与1086×1448、Key/Cup画风、16张适用原图、内容知识路径、四项双语文字、逐图查看、真实生图证据、受控连线及最终像素检查。
- 可变：主题、受众、合理分支与题数、问答分页、适用的general/home视觉分支。
- 收缩：移除视频专用图片、视频检查入口、独立英文稿和文案入口；不是降低内容完整度或视觉验收标准。
- 参考职责：Key/Cup画风；Cat/Dog整页节奏；Carrot紧凑主体比例；Dog/Lion练习版；Dog/Rabbit问答；家居篇加Window。具体生产以主skill为唯一规则入口，包装说明不另立相冲突的绘图规则。

源ZIP与插件内主skill逐文件保持字节一致：67个文件、16张PNG。相对于旧版源包，38个文件字节相同，移除6个视频/英文稿/文案专用文件，新增交付记录和纯图片打包脚本，27个文件因名称、输出范围和相关验收调整而改变。关键的 `check_manifest.py`、`manifest_model.py`、`content_coverage.py`、`connector_checks.py` 与 `render_connectors.py` 保持相同。

## 验收表

| 要求 | 执行动作与检查 | 证据或失败处理 |
| --- | --- | --- |
| 用户指定版本不变 | 校验原ZIP SHA256并逐文件对比插件内skill | `release.json`固定源哈希；不匹配则打包中止 |
| 原版并存 | 新增独立ID和目录，保留原条目与原技能文件 | 仓库差异检查；不替换原版manifest/skill |
| 完整安装入口 | 检查双manifest、独立本地来源和首次引导 | `scripts/check_plugin.py`及实际CLI安装 |
| 新电脑不靠作者路径 | 从交付ZIP在新路径解压，使用隔离Codex配置 | 读解压副本与安装缓存；缺文件即修包装 |
| 原规则可执行 | 完整性、参考解码、31项精简版回归 | 文件检查与程序行为和视觉美观分开报告 |
| 学习成品仅三类 | 内置skill范围、release deliverables、打包检查与现有警察实例 | 9组问答对应5张正式PNG，最终图片包已通过发布检查 |
| 接收者可独立开始 | 中文教程含安装、初始化、首次主题、并存、故障与迁移清单 | 包内入口；接收者真实生图尚待其本人验收 |

## 本次验证结果

操作者：本次Codex助手；环境：作者本机Windows、Python3.11.1、Pillow10.1.0、Codex CLI 0.163.0-alpha.11.1。以下均为实际执行结果：

| 项目 | 结果与范围 |
| --- | --- |
| 源包一致性 | 指定ZIP的SHA256与逐文件字节对比通过；原始ZIP另作为发布附件保留 |
| 精简版检查 | 双manifest、目录、来源、引导、77个包装清单文件及67个内嵌skill文件通过；参考PNG全部可解码 |
| 程序回归 | 精简版31项、原版30项全部通过；属于程序与合成反例验证，不冒充真实生图审美测试 |
| 技能元数据 | 主skill与新增setup均通过skill格式检查 |
| 新目录迁移 | 实际插件ZIP解压到含中文和空格的新路径，用隔离CODEX_HOME添加本地来源、发现、安装、启用成功；安装缓存副本再次通过完整检查 |
| 两版并存 | 从原版发布ZIP与新版迁移ZIP组装干净来源，在另一隔离配置中分别安装两版；均启用，两份缓存各自通过原有检查 |
| 损坏拦截 | 仅在解压测试副本中改动/移除参考图，均被检查拒绝；之后恢复测试文件 |
| 原版保持 | 原插件manifest、主skill、参考、release元数据、原安装指南未改变；仓库仅增加新版入口和维护检查 |
| 真实图片案例 | 先前本机警察主题：9组问答、2张导图与3张双语页，逐图检查及最终发布/纯图片打包通过；本次未重复付费生图 |
| 接收者复现 | 尚未由另一位使用者在其电脑、账号与工具下完成新主题；教程明确要求首次实际生图验收 |

测试时的隔离配置与缓存不写入用户当前Codex设置，不随包分发。一次并存测试把测试缓存放入了来源树中，因递归复制而中止；改为外部临时目录、由两个实际ZIP建立干净来源后安装通过。该问题属于测试目录选择，未以修改主skill或放宽检查处理。

原skill内部的MIGRATION/release记录是制作该源ZIP时的历史状态，随源文件原样保留；本次插件验证范围以本文件为准。GitHub发布后的远程获取与工作流状态可在仓库Actions及本次交付说明查看，不以本地测试代替远程结果。

## 适用边界

插件包自带参考、字体、许可、脚本和说明，不包含账号、登录态、生图服务、额度或发音评分。仅复制包不能给没有生图权限的环境增加图片工具。同机隔离安装不是另一台电脑或另一位使用者的实测；不得宣称接收者端到端已通过。

图片源文件中的品牌和参考只用于本系列既定制作，不额外授予任何第三方角色、商标等权利；字体许可见各字体目录。

## 正式入口与后续变化

从 [中文教程](INSTALL.zh-CN.md)开始，发布标签 `lite-v1.0.0`。主题输出按主skill标准依次为完整版、无字练习版及全部双语问答图片，正式主题ZIP只含PNG。内容/画风/连线实现变化时重查受影响成品；仅修改安装包装时验证包装、完整性与安装，不无故重生成全部参考。
