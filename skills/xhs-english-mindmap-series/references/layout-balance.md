# 左侧主体、标题与连线：居中布局和检查

适用于所有新建或修改的完整版导图及其练习版。保留本系列画风、紧凑主体比例、右侧分组及所有原质量要求。

## 制作前

1. 将左侧主体及其下方标题视为一个视觉单元，默认在左侧区域垂直居中。不是把人物移到整张画布的横向中央，也不是固定“头顶从页面中线开始”。
2. 在1086×1448页上标出主体真实外接框 `subject_box` 和标题真实框 `title_box`，以两框并集的垂直中心接近页面中线724px为目标。构图不同可以微调；不要照搬其他主题坐标。
3. 先定主体大小，再整体定位主体与标题，最后规划九个或实际数量的分支。主体缩小后必须重新检查位置，不能保留原脚底/下边缘导致整体下沉。保持右侧文字与插画可读尺寸，不靠挤压它们补救。
4. 练习版从通过的完整版派生，主体位置和大小保持一致，只移除标题与文字后，按真实图片群重画连线。

## 生成后、连线前

- 对照真实PNG确认外接框包含帽子、脚、背包等全部主体；标题单独量取，不把空白区写成主体来通过程序。
- `scripts/layout_checks.py` 的默认宽松拒绝线：整体中心应位于页高40%—60%。这是明显偏高/偏低的拦截线，不是保证美观的评分。练习版有完整版记录时，各主体边缘坐标差不得超过18px。
- 若版面需要调整，用图像编辑工具移动主体与标题；右侧已正确内容尽量保留。实际修好PNG后重新量框，重新规划连线；不能只改框、检查状态或例外来掩盖错误。
- 特殊构图仅在用户明确要求时使用 `layout_policy: {"version": 1, "mode": "user_directed", "user_instruction": "用户实际要求"}`。例外不豁免连线、练习版继承或人工视觉检查，脚本也不能认证这句话确由用户说过。

## 完整成品的检查顺序

1. 完整版全尺寸检查：人物及标题整体是否居中；标题是否紧邻主体；有无上方空太多、下方拥挤、帽子/脚裁切。
2. 将成品单独显示为350px宽，与Key/Cup、Dog、Carrot适用参考按相同宽度比较。观察整体视觉重心、上下留白和左右信息密度。数学中心接近中线，但观感仍失衡时必须修改。
3. 逐条追踪所有连线：起点靠近当前主体或标题真实边缘；终点对准自己的标题圈/图片群；主体上移后，上方线不应仍从原低位起笔，下方线应自然展开。拒绝穿人、穿字、交叉、密集并线、过长回钩和空白处断线。
4. 练习版与当前完整版等宽并排，确认主体的真实位置和大小一致，图片顺序及线索齐全，没有标题残影、文字、数字或空编号圈。
5. 在每图 `vertical_balance` 观察中写出真实框、整体中心/页高比例、手机宽度下上下留白判断、缩放后的定位结果；练习版再写与完整版对照结果。旧标准的通过记录不能代替这项新检查。
6. 重新生成比较图、记录检查结果、重建图库，再运行发布检查。布局变化会使旧连线、视觉检查以及依赖该封面的练习/问答继承证据待重查；如涉及改图，更新实际父图/样张链，不篡改历史时间。

## 本次反例与修正

消防员旧图主体框约 `[48,650,306,1240]`、标题框 `[40,1260,330,1306]`，整体中心978px，占页高约67.5%，明显偏低，即使人物高度紧凑也不合格。

修正版主体约 `[48,375,306,966]`、标题 `[40,986,330,1032]`，整体中心703.5px，约48.6%。这是本次真实修正案例的数值，不是所有主题通用坐标。用户提出居中要求；修正版已经助手查看，不把未明确获得的额外用户美学认可写成已批准。
