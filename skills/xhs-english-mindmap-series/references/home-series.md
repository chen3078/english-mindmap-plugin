# Home-series visual anchor: owner-approved Window

Use this reference for later home-object topics, alongside the general Key/Cup/Cat/Dog references. The owner approved the **exact** Window cover in `../assets/approved-window/cover.png` and then accepted its picture-only practice map and two finished bilingual Q&A pages. These four files are positive references. Earlier Window drafts in the topic workspace and the earlier Door versions are not visual templates.

The established home-series topics are Door, Window, Bed, Lamp, Sofa, Table, Chair, Clothes, Fridge, Washing Machine, Cup and Umbrella. Apply the home treatment to these topics in this series even when the manifest's broad category is `everyday_object`; a user-specified different visual direction takes precedence. For other topics, use the requested category and series context rather than silently applying home decorations.

## What changed between failed and accepted pages

| Format | Repeated failure | Accepted Window cue |
| --- | --- | --- |
| Cover | Static tall object, repeated square whole-object icons, distant label/icon columns, mechanical equal rows, hard or inconsistent fills | A recognizable open window with a wide silhouette and soft gingham/wood/flower motifs; close-up parts, opening actions, buildings and room scenes alternate; headings and pictures read as one connected page at phone width |
| Picture-only | New composition unrelated to the chosen cover, or empty circles/labels left behind | Same main window and eight picture groups in the same order and positions as the selected cover; no words, title, brand, numbers or circles; connected groups remain legible |
| Bilingual Q&A | Self-made card styling copied Dog's colors but produced heavy or thin type, dense Chinese, pasted-looking art, and a different whole-page rhythm | `../assets/approved-window/qa-01-04.png` and `qa-05-08.png`: Dog-like full-page header and four softly washed horizontal rows, prominent Q/A hierarchy, readable Chinese, relevant art flowing into each row |

The crucial failure was **acceptance by proxy**: passing a manifest, line count, dimensions, and file count was treated as passing the visual template. Some comparisons were made but failed candidates were still described as a match. A new candidate must be judged against the actual full reference pages at the same 300–400 px width. If its overall shape, image vocabulary, type hierarchy, or page density is visibly different, revise it before presenting it as template-matched.

## Door/Window lessons: requirements before generation and after each export

The following standards apply to later home topics as well as repairs. Earlier production notes sometimes recorded a visual pass for a candidate the owner subsequently rejected. A written pass is therefore not evidence by itself; the actual candidate, reference comparison and specific observed relationships must support it. These lessons concern visible output and recorded workflow; do not invent an unobserved failure of a provider or a missing historical tool call.

| Earlier visible failure | Requirement in the next generation/composition brief | Evidence required after export |
| --- | --- | --- |
| A tall, oversized Door/Window dominated the page, or a shrunken replacement left the page empty | Plan the subject's silhouette and scale together with the readable right groups. Use Carrot for compact size only and Window for the home treatment. Size percentages are initial guidance, never an aesthetic pass. | At equal page width, compare the actual subject/title/group balance and empty spaces. Reject both a dominant tall slab and a tiny isolated object. Do not shrink the right-side teaching content to fit the subject. |
| Numbered headings formed a detached middle sidebar; pictures and keywords sat far away | Compose each heading at its branch tip together with its own nearby studies and captions. Give groups the space their actual picture counts require. | Follow heading → pictures → labels for every group; reject a detached heading column, large unexplained gap, unrelated intervening picture or rigid equal-height grid. Ordinary descriptive callouts such as Cup's Looks arrows are allowed when they belong to that picture. |
| Many groups reused the same whole window or rectangular room view | Choose a meaningful mixture of whole-object, enlarged part, action, material, location and scene studies appropriate to the content. | Identify how adjacent groups differ in silhouette and information. Several nearly identical whole-object tiles are not variety merely because captions differ. Parts named in the answer must each have a clear local study. |
| Hard outlines, heavy wood fills, mismatched assets or a generic clip-art object | Define one recognizable topic design and a shared ink, grain, palette and edge softness. Apply the home-series soft, comfortable, cute treatment without losing the material/function. | Main subject and mini studies visibly belong together. Hard surfaces stay believable; warmth comes from softened contours, restrained shading, textiles where relevant and inviting proportions, not arbitrary faces or cushions on every object. |
| The object changed design between main picture, studies, practice and Q&A | Specify the subject's shape, color/material and meaningful recurring motif; use accepted current-topic art as the subject reference. | Compare the same object across pages. Explicit kinds/material variations are allowed where taught; accidental redesigns are not. Do not import reference animals or Window curtains into unrelated objects. |
| A text-free Q&A background was shown as the requested page | Classify the output before the call. Q&A generation must request a complete page with all assigned English/Chinese questions and answers. Only isolated art may be text-free in the separate-art method. | Each delivered Q&A row contains its four exact fields; a blank full-page Q&A sheet fails even when described as an intermediate for later text. Mind-map practice and video stills have their own no-text rules. |
| Q&A matched pastel colors but looked unlike Dog/Window as a whole page | Use the actual approved Dog and Window whole-page references. Plan the header, number disks, Q/Chinese/A/Chinese reading order, broad watercolor rows and integrated art as one composition. | Compare the whole-page hierarchy, row spacing/fill, large handwritten English, quieter readable Chinese and page density. Matching colors or row count alone is not a match. |
| English was too thin/small, Chinese too heavy/dense, or art looked pasted on | Allocate space for the real bilingual text first; integrate relevant art without tiny thumbnails, opaque crop rectangles or text overlap. Add a page when needed. | Read every question and answer at full size, then check the apparent English/Chinese hierarchy at phone width. Reject cramped line breaks, small type, pasted backgrounds, isolated mini-art and unused space that disconnects text from art. |
| A failed candidate was regenerated with essentially the same layout | Write the exact failed relationship and the concrete design change before the next call; change the composition/art vocabulary or method that caused it. | Compare the rejected finding with the new raster, not just the new filename. If the same failure remains, keep the failed status, reassess the plan and stop batch work for that format. |
| The accepted original was replaced by a technically reworked image | Preserve the user's exact selected bytes as the approved artwork. Make any proposed correction a separate candidate. | Confirm which actual file was selected. Connector checks and editable text do not authorize silently substituting a different visual result. |

## Required home-topic generation brief

Before the first image call, put these decisions in `prompt-notes.md` and incorporate the applicable ones into the actual prompt/composition plan, not just the review notes:

1. **Reference roles and actual inputs:** which approved files control style, composition, subject scale and the current subject. Open them first and supply applicable images as actual inputs.
2. **Topic identity and home treatment:** one concrete silhouette, palette/material and motif; explain how softness/comfort/cuteness fit this object without changing its function.
3. **Cover relationships:** compact subject/title balance, headings attached to their own studies, keywords beneath the corresponding pictures, organic branch rhythm and deliberately varied studies.
4. **Q&A whole-page plan:** frozen page ranges, exact four fields per question, Dog/Window family, readable type hierarchy and integrated art. Follow [production-workflow.md](production-workflow.md) for method selection.
5. **Practice continuity:** preserve the selected cover's artwork and grouping while removing all text/circles and checking every connector.
6. **Previous failure, when revising:** state the observed defect and the actual layout/art/text change. Repeating adjectives such as “cute, neat, cozy” without changing the failed design is not a correction.

After each final PNG, use [image-review.md](image-review.md). The per-image report includes distinct scale, heading/picture relation, study variety, Q&A template/integration and home-softness criteria so these lessons are checked individually. A structural PASS or a generic “looks good” must not replace those observations. No new-topic quality claim is established until a real new-topic run passes these checks.

## Production decisions that worked

1. **Cover:** pass the actual Key, Cup, Cat, Dog and, for home objects, approved Window PNGs as image references when generating art. Give the object its own memorable silhouette and soft, comfortable details; do not mechanically copy Window's gingham curtains to a bed, sofa, lamp or appliance. Mix whole-object views with part studies, actions and small scenes, as the topic requires. Compare the full candidate at phone width before proceeding.
2. **Owner selection is exact:** when the owner points to a particular generated picture as “这一版才对”, retain that exact file as the approved cover. Do not silently replace it with a connector-reworked or re-typeset variant. If a technical defect matters, show the proposed correction separately and obtain a new visual decision. The accepted Window cover was the original whole-page generation, not its later connector-reworked derivative.
3. **Practice:** derive it from the *selected* cover as an edit, preserving the main subject, group order and recognizable drawings. Check the exported whole page against `../assets/approved-window/picture-practice.png` and Dog/Lion finished practice references; remove all text and numbered circles. Check each branch visually; a line-free base or connector script pass is insufficient.
4. **Q&A:** select the method and execution order under [production-workflow.md](production-workflow.md). Plan complete pages from the frozen manifest. Make a **finished text-bearing sample** using actual Dog and approved Window Q&A whole-page references plus current-topic subject art. Complete-page generation is the preferred new-topic method when reference-image and bilingual-lettering support are suitable; it is the method that worked for Window. Compare the sample at phone width and check every English/Chinese field against the manifest. Separate-art typesetting is a fallback and must meet the same exported-page standard. Never display an empty Q&A sheet. Use the accepted sample as an additional reference for remaining pages and compare every finished page with Dog/Window before release.
5. **Video stills:** use Dog only for scale and bottom subtitle-space framing. For a new home topic, use the approved current-topic cover and Q&A art as subject references, then a successful topic still for later stills. A Dog picture used as a generation reference can introduce an irrelevant dog; reject any such subject leakage. Check the lower 25% for a clean paper zone without a straight crop edge.

## Review record for each new home topic

Record in `prompt-notes.md`: which exact reference files were passed to generation; which full-page candidate was compared at phone width; one concrete pass/fail finding for cover, practice and each Q&A page; any rejected candidate's *changed composition* in the next attempt; and the owner's selected cover file. Do not call a self-reviewed candidate owner-approved. Stop subsequent image formats when the owner asks to review only the cover.
